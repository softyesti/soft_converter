# CHANGELOG

## 0.4.0

* Updated examples.
* Improvements to the code documentation.
* Added automatic packaging of dependencies via `build_hooks` and `data_assets`
if the Flutter installation is compatible.

## 0.3.0-dev

* Updated examples.
* Added feature: Multiple conversions.

**BREAKING CHANGE**: New function signature for the `toWEBP()` and `toWEBM()`
methods. Check the examples.

## 0.2.0-dev

* Added feature: Convert `.mp4` videos to `.webm`.

## 0.1.1-dev

* Removed `cwebp` binaries from package.
* Added field for `path` to `cwebp` binary(optional).

## 0.1.0-dev

* Added exceptions: `Process` and `PathNotFound`.
* Added feature: Convert `.jpg` and `.png` images to `.webp`.
